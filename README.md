# TuNominaYa
Aplicación destinada a optimizar la creación, administración y visualización de las nominas de la empresa.

Esta aplicación tiene como propósito optimizar la creación de nóminas dentro de las empresas de la república dominicana, dándoles esas facilidades de auditoria y manejo que muchas veces un excel no tiene.

Por ahora es un proyecto que esta iniciando, espero que los disfruten.
